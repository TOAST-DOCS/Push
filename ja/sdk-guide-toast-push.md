<a id="notification-push-sdk-guide"></a>
## Notification > Push > SDKガイド { #notification-push-sdk-guide }
NHN Cloud Push SDKを適用すると、モバイルアプリケーションで簡単に、強力なNotificationサービスを提供できます。

<a id="main-features"></a>
## 主な機能 { #main-features }
* OSに通知トークンを登録
* 通知メッセージの受信および表示
* メッセージの受信および受信したメッセージからアプリケーション実行指標を収集
